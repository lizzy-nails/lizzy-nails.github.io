# Как работать в этом репозитории

Пользователь пишет запрос на изменение сайта — ты его выполняешь целиком, без лишних уточнений:

1. Внеси правку в код (`index.html`, `style.css`, `app.js`, `nails.js` — см. README.md).
2. Проверь результат, насколько это возможно (синтаксис JS, вёрстка на телефоне и десктопе).
3. Закоммить в `main` и запушь в `origin` (`git push origin main`) — подтверждение не нужно.
   GitHub Pages сам опубликует сайт: https://lizzy-nails.github.io
4. Коротко ответь, что сделано и что уже залито.

Спрашивай только если запрос действительно непонятен или правка может что-то сломать (например, запись клиентов).

## Коммиты

- Сообщение короткое, на английском, в стиле истории (`Fit hero heading on phones, stop sideways scroll`).
- Не добавляй `Co-Authored-By` и любые другие упоминания Claude/ИИ в коммиты — себя в контрибьюторы не вписывай.
- Автор коммита — настроенный в git пользователь, ничего не меняй в `git config`.
