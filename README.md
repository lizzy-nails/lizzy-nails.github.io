# nail-master-landing

Лендинг мастера маникюра (POC): статический HTML/CSS, без сборки, публикуется через GitHub Pages из ветки `main`.

- `index.html` — разметка (услуги, работы, обо мне, отзывы, запись, контакты)
- `style.css` — стили

Плейсхолдеры, которые нужно заменить: имя мастера, адрес, телефон, ссылки на Telegram/WhatsApp, цены.
Форма записи пока ничего не отправляет — подключить Telegram-бота или Formspree.

Локально: `python3 -m http.server` и открыть http://localhost:8000.
